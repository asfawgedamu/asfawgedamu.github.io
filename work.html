Tigrinya Dialect Identification

Research, NLP

A dataset and benchmark for telling three Tigrinya varieties (L, Z and D) apart from text alone. Sentences were collected per dialect from books and social-media writers, then translated into the other dialects with native-speaker experts.

A character-level CNN reaches 92.98% accuracy on Ge'ez-script text.

Tigrinya Dialect Identification

Asfaw Gedamu Haileslasie, Asmelash Teka Hadgu and Solomon Teferra Abate

Language technology for Tigrinya starts with data, and for dialects that data barely existed. Beyond the dataset, the paper proposes a shared taxonomy of the three varieties and compares classical machine learning with deep learning. Character-level convolutional networks performed best.

API Design Fundamentals

Backend, teaching

A progressive FastAPI lab series that moves developers from calling APIs to designing them. It uses a restaurant analogy: the customer is the client, the waiter is the endpoint, the kitchen is the service layer and the warehouse is the database.

Three standalone apps that build on each other, each with its own README.

Code How the three levels differ

How the three levels differ

Each level is a complete app with its own README, and each adds one idea about how a backend should be organised.

Fundamentals, in one file

Directory /basic, runs on port 8000. Data lives in memory, so the focus stays on how requests and responses work.

  • FastAPI basics and HTTP methods
  • JSON payloads and the generated OpenAPI and Swagger UI
  • A single-file app, app_basic.py

Persistence and validation

Directory /intermediate, runs on port 8001. Data moves into SQLite, and every request is validated before it touches the database.

  • Full CRUD: POST, GET, PUT and DELETE
  • SQLAlchemy ORM with Pydantic validation
  • Versioned routes under /api/v1/, CORS and pagination

Layers, security and tests

Directory /advanced, runs on port 8002. Routes stay thin, services hold the rules, and the database sits behind them.

  • Layered modular layout: app/routes and app/services
  • API keys and JWT authentication
  • Structured logging, performance middleware and Pytest with HTTPX
